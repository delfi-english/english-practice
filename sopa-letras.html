Sopa de Letras Dinámica 🔍

Arrastrá el dedo (o el mouse) sobre las letras para marcarlas. Podés marcar varias y comprobarlas al final. Podés marcar una palabra en partes, tocar una letra suelta para marcarla y tocarla de nuevo para desmarcarla.

También podés presionar "Enter" en tu teclado para comprobar.
